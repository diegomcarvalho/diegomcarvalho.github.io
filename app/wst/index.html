📅 WhatsApp Agendado

Cria uma tarefa no TickTick com o link pronto do WhatsApp

Gere em ticktick.com → avatar → Settings → Account → API Token. Fica salvo apenas neste navegador (localStorage).

Como funciona

1. Você preenche contato, mensagem e horário.
2. O app monta a URL https://wa.me/<numero>?text=<mensagem>.
3. Essa URL vai no campo "content" de uma tarefa criada via API do TickTick, com o vencimento (dueDate) no horário escolhido.
4. No horário, o TickTick notifica você. Ao abrir a tarefa e tocar no link, o WhatsApp abre com a mensagem pronta — só falta tocar em "Enviar".
